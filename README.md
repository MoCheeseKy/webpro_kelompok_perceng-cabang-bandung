# TelU Hub 🎓

> **TelU Hub** adalah platform berbasis web yang menyediakan ruang tulisan, forum diskusi komunitas, dan rekomendasi tempat di sekitar kampus untuk mahasiswa Telkom University.

## 📄 Daftar Halaman

1. **`index.html`** - Halaman utama/beranda (rekomendasi tempat populer, diskusi terbaru, tulisan pilihan).
2. **`login.html`** - Halaman autentikasi/masuk untuk akun mahasiswa.
3. **`register.html`** - Halaman pendaftaran akun mahasiswa baru.

## 🚀 Cara Menjalankan

1. Clone repositori ini ke komputer lokal:
   ```bash
   git clone <URL_REPOSITORY>
   ```
2. Buka folder proyek di file explorer atau text editor (VS Code).
3. Buka file `index.html` langsung di browser atau gunakan ekstensi **Live Server** di VS Code.
